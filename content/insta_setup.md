# Meta Graph API — بازنشسته (غیرفعال)

> مسیر Meta Graph API به‌طور کامل کنار گذاشته شده است. `build/insta_publish.py` فقط یک پیام خطا چاپ می‌کند و هیچ قابلیت انتشاری ندارد.
> انتشار فقط از طریق API رسمی Buffer (`build/buffer_publish.py`) و پشت ناظر کیفیت + متغیر `AUTO_PUBLISH_ENABLED` انجام می‌شود.

اگر روزی خواستید این مسیر را برگردانید، تمام مراحل (توکن بلندمدت، `IG_USER_ID`، صف زمان‌بندی) باید از نو طراحی و بازبینی امنیتی شوند؛ هیچ اسکریپت یا ورک‌فلوی فعالی در این مخزن به آن‌ها اشاره نمی‌کند.
